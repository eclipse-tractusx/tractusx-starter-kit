Early development

The Starter Kit is being built. The configuration wizard and generated Docker Compose setup are not available yet.

Our goal is to help newcomers reach their first data exchange in about 15 minutes using existing Tractus-X components, without Kubernetes or Helm. This is a local development and evaluation starter, not for production use.

Getting started
