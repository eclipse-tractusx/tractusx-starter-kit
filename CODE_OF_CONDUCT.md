# Community Code of Conduct

Participation in this project is governed by the
[Eclipse Foundation Community Code of Conduct](https://www.eclipse.org/org/documents/Community_Code_of_Conduct.php).
The applicable policy is version 2.0, dated January 1, 2023.

We are committed to a welcoming, inclusive, and harassment-free community.
Treat other contributors with respect, welcome differing perspectives, and
offer constructive feedback.

Report unacceptable behavior confidentially to the Eclipse Foundation Conduct
Committee at [conduct@eclipse-foundation.org](mailto:conduct@eclipse-foundation.org).
The linked policy defines the scope, responsibilities, and enforcement process.
