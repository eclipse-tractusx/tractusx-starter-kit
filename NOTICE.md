## Third-party Content

The initial static documentation site bundles no third-party libraries, fonts,
images, or runtime dependencies. GitHub Actions dependencies are declared in
`.github/workflows/` and maintained by Dependabot; they are not shipped with the site.

Before each release, generate and review a `DEPENDENCIES` inventory using
[Eclipse Dash](https://github.com/eclipse/dash-licenses), and publish it alongside
the release's SBOM as applicable. See the
[release prerequisites](INSTALL.md#release-prerequisites); no release inventory
or SBOM has been produced yet.
