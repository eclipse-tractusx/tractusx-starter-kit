# Security Policy

## Supported Versions

The Starter Kit is in initial development and has no released versions.
Security fixes are applied to `main`. It is intended for local development and
evaluation, not production deployments.

## Reporting a Vulnerability

**Do not report vulnerabilities in public issues or pull requests.**

Use the repository's [private vulnerability reporting form](https://github.com/eclipse-tractusx/tractusx-starter-kit/security/advisories/new).
If private reporting is unavailable, or for severe vulnerabilities, follow the
[Eclipse Foundation vulnerability reporting process](https://www.eclipse.org/security/).

Do not include credentials, personal data, or sensitive configuration in reports.
